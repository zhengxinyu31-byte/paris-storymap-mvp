Paris StoryMap：交互功能与用户动线梳理
2026-10-06 · 对照实际页面、路由、状态与浏览器操作

1. 主线是什么

用户的目标：找到适合自己的巴黎故事线，并沿地点顺序理解故事。
人格测试是首次推荐入口；地图与连续阅读构成日常使用的核心；人物、作品和知识库是可自由进入的补充。

首次使用：
四道旅行偏好选择 → 人格解析 + 一条推荐 → 路线地图 → 选中 POI 卡片 → 主故事正文
                                                        ↑                      ↓
                                                        └──── 下一站卡片 ← 读完本章

结束时：
最后一章 → 阅读回顾 → 有未读章节：继续未读章节 / 无未读章节：回看地图

返回使用：
打开首页 → 上次选择的路线和章节位置 → 点击“继续第 N 站”

可选捷径：
不想测试 → 直接选故事线 → 路线地图
已知地点 → 探索地点 → 查找或点卡片 → 自由阅读
共享链接 → 对应路线、地点故事或人物足迹；不强制补做测试。

2. 原先为什么会觉得乱

- 默认落到 NERD 地图，用户未作选择就被放进一条路线；人格测试成了外围入口。
- 顶部“故事线”、人格下拉、路线页换线、探索页推荐区都能选路线，入口职责重叠。
- 探索地点页先呈现测试和六条路线推荐，找地点的人需要再次经过选线内容。
- 故事正文旁同时铺开同址故事与相关路线，主故事尚未读完就出现大量离开入口。
- 人物标签、人物补充、问答说明、来源、访问说明的层级不够明显。
- “读完继续”直接跳到下一篇正文，地图、地点顺序和现实空间在阅读中被绕过。
- Logo 固定跳到 NERD；用户离开主线后缺少统一、可靠的返回位置。
- 从收藏打开故事，返回按钮却指向探索地点；搜索返回与刷新容易丢失筛选条件。
- 共享 POI 切到另一条路线时从第 1 章开始，地点上下文断开。
- 直接读最后一章也显示尾声，原主要按钮没有优先带用户补读之前的章节。

3. 本轮采取的方式

优先减少重复入口和错误返回，再用短提示帮助用户理解下一步。采用页面内提示；未增加强制教程弹窗或额外的引导步骤。

导航层：我的路线 / 探索地点 / 我的收藏，另保留全局语言。
首次尚未选择路线时，“我的路线”位置显示“旅行人格测试”。
Logo 与“我的路线”回到当前路线，不固定切回 NERD。
换线保留在路线页和主动展开的相关路线中；重新匹配可从换线面板进入。

地图层：地图为主体，默认不平铺 POI；提示“按数字顺序游览，点地点读故事”，给出“从第 N 站开始 / 继续第 N 站”按钮。
阅读层：主故事全文、必要的争议说明和观察提示优先；“前往下一站”位于人物补充和实用信息之前。
补充层：深入了解、同址故事和换线入口默认折叠。人物/作品标签仍可直接进入足迹。
返回层：区分我的路线、原章节、人物足迹、搜索结果、收藏来源；不再用一个含糊的返回动作替代所有来源。

4. 完整功能与链路清单

A. 旅行人格测试
入口：首次首页；路线页“换一条故事线”内的测试入口；#/quiz。
操作：三选一、自动进入下一题、上一题、修改答案、刷新恢复、双击防重复提交。
去向：第四题后自动进入人格解析与推荐；也可直接选择故事线。
状态：答案独立保存，不改收藏或阅读记录。四题覆盖四个偏好维度，81 种答案组合可落到 16 种人格。

B. 人格结果与路线推荐
入口：答题结束；有效答案对应的 #/quiz/result。
操作：查看解析、四个偏好、推荐原因、路线概况；开启路线；重测、修改选择、看其他路线。
主要去向：推荐路线的大地图。
异常：缺少或损坏答案时返回问题，不凭空生成结果。

C. 当前路线与路线切换
入口：推荐结果；直接选择；我的路线；收藏路线；共享链接。
操作：展开简介、换线、收藏、分享；地图总览、缩放、拖动、点选站点。
状态：保留当前路线与章节位置。浏览支线、探索地点或查看另一份人格结果，不自动改写当前路线。
首次进入地图不自动展开卡片；明确点站点或“开始/继续”后才展开。

D. POI 地图卡片
入口：点地图标记；开始/继续按钮；上一站/下一站；读完上一章。
内容：照片、站序、章节、故事标题、摘要、已读/跳过状态、下一站地点。
操作：关闭卡片、上一站、下一站、读故事、外部导航。
去向：当前 POI 的主线故事；前往下一站的外部地图。
边界：切换卡片不会自动标记已读，也不代表已经实际到访。

E. 主线故事阅读
入口：路线卡片的“读这则故事”。
内容：地点照片与地址、所属路线和章节、年代、证据标签、正文、人物关系、必要的传说辨读、观察提示。
操作：收藏、分享；标记读完/跳过；进入人物或同址支线；展开资料。
去向：普通章读完 → 下一站地图卡片；最后一章 → 阅读回顾；顶部返回 → 当前站地图卡片。
状态：仅主线阅读写入该路线的进度；读完与跳过分别计数。

F. 深入了解与来源
入口：正文内“深入了解这则故事”、出处面板；正文后人物补充与实用信息。
操作：展开问题，查看“为什么在这里 / 人物关系 / 今天看什么 / 细节辨读”；查看来源、人物资料和访问说明。
去向：大部分在原页展开；来源、官方参观信息与地图查找在外部页面打开。
边界：争议标签与必要的正文说明仍保留；折叠是信息层级调整，不删除史实限定。

G. 同址其他故事
入口：主动展开“同一地点，还有这些故事”。
操作：选择另一则故事；标记自由阅读完成；进一步进入人物足迹。
去向：补充故事正文；“返回原来章节”回到最初的主线故事。
状态：不推进主线。返回目标保存在 URL，刷新后仍可返回；不重复列出正在读的同一则故事。
没有其他故事时不显示空入口。

H. 人物/作品足迹
入口：正文人物/作品标签；人物补充；问答中的人物；足迹页的关联人物。
操作：选择相关事件、选择对应地图点位、查看预览、打开故事、继续查看关联人物。
去向：另一处 POI 的故事；回到人物足迹；回到出发的故事；我的路线。
状态：保存 origin、trail、event；在支线之间切换和刷新不会推进主线。
边界：按资料中的明确年份排列，不伪造成完整生平；人物地图显示地点分布，不替代巴黎主题游览路线。

I. 从共享 POI 换线
入口：主动展开“从这里换一条故事线”。
操作：选择含有此 POI 的其他主题。
去向：新路线中同一 POI 的地图卡片，展示新路线选用的故事；不跳到无关的第 1 站。
状态：这是明确换线动作，会更新“我的路线”。当前路线不重复列出；没有其他路线时不显示空入口。

J. 探索地点与搜索
入口：主导航“探索地点”；自由阅读返回。
操作：浏览地点卡片；搜索地点、人物、作品、正文关键词；快捷主题筛选；清空筛选。
去向：地点的自由阅读故事；从那里再进入同址故事或人物足迹；我的路线。
状态：搜索词写入页面链接，刷新和从故事返回后保留；中文、英文与重音归一化搜索共用数据。
调整：移除重复测试横幅和六条推荐路线，探索页集中展示地点。

K. 收藏
入口：路线/故事书签；主导航“我的收藏”。
操作：收藏与取消收藏，打开收藏面板，选择路线或故事，关闭面板。
去向：收藏路线进入地图；收藏故事按自由阅读打开，返回按钮回到收藏面板。
状态：收藏列表与阅读记录保存在当前浏览器。故事收藏不自动变成当前主线。
空状态说明如何收藏。刷新收藏故事后仍保留收藏来源。

L. 阅读回顾
入口：主线最后一章的读完或跳过。
内容：路线尾声、已读、跳过、待探索数量。
操作：有未读章节时优先继续未读章节；否则回看地图；也可换另一条故事线。
边界：这是阅读回顾，不是实际完成步行的证明。仅点开最后一章不等于读完整条线。

M. 全局语言、链接与通用操作
语言：菜单选中文/英文，保留页面、选点、测试答案、收藏和阅读状态；刷新后恢复选择。
分享：复制当前页面的完整直达链接；首页恢复的路线也包含路线与章节参数，其他人打开不会误入测试。剪贴板不可用时打开可选中的链接输入框。
路由：路线、地点、人物、测试均可直接链接；非法对象有回退；返回参数校验以避免递归或外部跳转。
弹窗：关闭按钮、点击遮罩、Escape；Tab 焦点限制在弹窗内，关闭后恢复原焦点。
地图：底图失败时显示有坐标的顺序示意图，仍可点选；路径按游览顺序统一连线，不区分交通方式。
图片：使用本地正确地点图片；失败显示可读降级内容；按横竖画框设置焦点。
存储：不可用时仍可当次阅读、答题和切换语言，但无法保证跨次恢复。

5. 主支线返回规则

当前路线 → 主故事 → 人物足迹 → 关联故事 → 原主故事：主线章节不变。
当前路线 → 主故事 → 同址支线 → 原主故事：主线章节不变。
当前路线 → 探索地点 → 自由故事 → 我的路线：回到原路线位置。
探索搜索 → 地点故事 → 返回探索：原搜索词保留。
收藏列表 → 收藏故事 → 返回收藏：回到列表；不错误进入探索页。
主故事 → 明确换线 → 新路线同址卡片：当前路线随用户选择更新。
主故事 → 读完 → 下一站地图卡片：这是正常推进主线的动作。

6. 后续如何判断还需不需要教程

优先观察几位第一次使用的人能否：完成四题后进入推荐；在地图找到第一站；读完后理解为什么回到地图；进入支线后返回；下次打开继续原路线。
如果卡在某一步，只调整该步的文案、位置或提示。只有操作本身难以理解时，再增加一次性提示。
本轮没有新增行为追踪服务；这些是可执行的用户观察任务，不是已经采集到的指标。

后续候选：搜索空结果提示、支线过长时的轻量返回条、路线按地区/节奏分组、完成一段后更自然的回顾。
暂不增加：对话式规划、强制多页教程、复杂任务体系、多个同级推荐首页。
